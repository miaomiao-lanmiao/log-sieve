# Log Sieve v0.2.0

Date: 2026-10-31 (Asia/Shanghai). Release draft.

- Recognize standalone Node-style error headers without an explicit ERROR level.
- Keep common Python traceback source context and chained exceptions in a single
  incident. Independent repeated tracebacks remain separate occurrences.
- Support Python logging timestamps containing comma-separated milliseconds.
- Redact HTTP Basic credentials and values that contain a redaction placeholder
  as only part of their contents.

All 34 local tests passed, including eight new behavioral cases. Seven failed
against the previous version. Build, offline installation and hosted CI are the
release gates. Existing CLI flags and JSON schema 1 remain supported; improved
recognition can change unknown/error counts for newly supported log formats.

```sh
npm install --global ./log-sieve-cli-0.2.0.tgz --ignore-scripts
logsieve analyze python-error.log --format html --output review.html
```

Heuristic detection and redaction are incomplete. Review reports before sharing.
No npm registry publication or real service request is performed.
