# Log Sieve v0.1.1

Maintenance release draft, 2026-10-23 (Asia/Shanghai).

- Normalize terminal styling and direction controls before credential matching,
  including decoded JSON strings and credential field names.
- Redact private-key markers split by terminal styling while retaining original
  source line references.
- Use a single tool version for CLI, JSON metadata and HTML reports.

Five new regressions reproduce the prior omissions. All 26 local tests, the
TypeScript build and offline package installation passed. Hosted Linux, Windows
and macOS checks are required before creating this draft.

Redaction remains pattern-based and incomplete. Review reports before sharing.
The JSON schema remains version 1, and existing CLI arguments remain compatible.

```sh
npm install --global ./log-sieve-cli-0.1.1.tgz --ignore-scripts
```

Requires Node.js 22+. No npm registry publication is performed.
