# Log Sieve v0.1.0

Initial release draft.

- Parse text/JSON Lines and common stack traces; group repeated warnings/errors.
- Redact common credential patterns before grouping, retaining deterministic line
  references and reporting pattern-match counts honestly.
- Export Markdown, JSON or standalone HTML, with eight troubleshooting rule
  categories and optional CI thresholds.

Requires Node.js 22+. Download the attached tarball and install locally:

```sh
npm install --global ./log-sieve-cli-0.1.0.tgz --ignore-scripts
logsieve --help
```

The package has no runtime dependencies and is not an npm registry publication.
Redaction is incomplete; review generated reports before sharing them. Diagnostic
checks are hypotheses and no automated changes are performed.
